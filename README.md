Practica 2 de dispositivos.

La mejora dentro del proyecto ha sido la de añadir la opcion de reiniciar asi como la implementacion de un cambio de color de la bola completamente aleatorio cada vez que esta impacte con un bouncer.
Por otro lado se ha añadido una pintoresca decoración del entorno de la habitación con objetos proporcionados en el propio proyecto.
